# Scénarios du PC Attaquant

À choisir et faire valider avec le coach : attaque principale reproductible, effet métier
observable, indicateurs ML, action de reprise et test d'une nouvelle transaction.

Documenter : machine source distincte, adresse du PC Hôte, ports autorisés, durée,
conditions d'arrêt, collecte de preuves, données fictives et procédure de remise en état.
Aucun script offensif n'est lancé par le setup. Les réseaux tiers restent hors périmètre.
Un test local d'arrêt de conteneur peut aider au développement mais ne remplace pas
l'attaque depuis le deuxième PC attendue pour la soutenance.
