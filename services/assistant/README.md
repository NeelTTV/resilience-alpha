# Assistant documentaire

`main.py` découpe les documents locaux en objets Document LangChain, recherche avec
TF-IDF et génère avec ChatOllama. Sources/extraits renvoyés avec mode explicite :
rag, retrieval_only ou no_source. Modèle CPU qwen3:0.6b par défaut ; allowlist <=8B.
Aucun droit de commande, secret d'administration ou accès à la politique de reprise.
